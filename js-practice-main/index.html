JavaScript Basics Practice

Everything happens in the Console today.

  1. Press F12 and click the Console tab.
  2. Open practice.js in VS Code and work through the tasks.
  3. Save after each task. The page reloads and your answers appear in the Console.
  4. Compare your output with the EXPECTED OUTPUT under each task.

Red text in the Console means an error. Read it: it tells you the line number.
